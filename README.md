# AeroX
Roblox Support Community Website

## Description
AeroX Executor is a Roblox community support platform. This website provides installation guides, support tools, community news, and resources for Roblox players.

## Features
- Installation guides for Android and iOS
- Support tools and resources
- Community news and updates
- Roblox scripts section with sample code
- User registration and community access

## How to Run
1. Start the server: `python3 -m http.server 8000`
2. Open http://localhost:8000 in your browser
